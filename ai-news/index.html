为什么用 RSS 追 AI 进展

  • 不漏一手信息：模型发布、安全公告、研究论文通常先在官方博客出现，媒体要晚几小时到几天。
  • 不被算法左右：订阅谁就看谁，没有推荐流与信息茧房，也不依赖平台是否给你推。
  • 可以存档与检索：RSS 是结构化数据，能进阅读器全文检索，也能喂给自己的知识库或自动化流程。
  • 成本最低：一个 XML 请求，不需要 API Key，不受频率限制影响。

常见问题

RSS 是什么？现在还有必要用吗？

RSS 是一种把网站更新打包成标准 XML 的协议。相比算法推荐的信息流，RSS 的好处是「你订阅谁就只看谁」：不漏掉你关心的实验室更新，也不会被无关内容淹没。AI 领域很多一手信息（安全公告、模型发布、研究论文）只在厂商博客发布，用 RSS 订阅是最省时的跟踪方式。

本页的 RSS 源怎么订阅？

把 https://www.kyhsexport.com/ai-news/rss.xml 粘贴到任意阅读器（Feedly、Inoreader、NetNewsWire、Reeder、FreshRSS、Zotero 的 RSS 功能等）的「添加订阅源」输入框即可。也可以点页面上的 Feedly / Inoreader 按钮一键添加。订阅源收录最近约 100 条聚合资讯，每日更新。

为什么有些源要经过 GitHub 仓库中转？

Anthropic、Mistral、Ai2、xAI、Thinking Machines 等站点本身不提供 RSS（或已下线）。两个开源仓库 alan-turing-institute/ai-rss-feeds 与 0xSMW/rss-feeds 用 GitHub Actions 定时抓取这些页面并生成标准 RSS 2.0 feed，本页直接消费它们。这样既补上了缺失的官方源，也保留了全文与配图。

资讯多久更新一次？会不会重复？

每天自动同步一次，按发布时间倒序合并，并对链接与标题双去重，所以不会出现同一篇文章重复出现。某个源临时抓取失败时，会保留它上一版的历史条目，页面不会突然变空。
