这张比价表怎么读

每一行是一个「产品 + 套餐 + 计费周期」。最低价是该套餐在全部可比地区里的最低人民币折算价， 美国价是美区价格，比美区一列表示相对美区便宜（绿色）或更贵（红色）多少。 点表头可以按价格、差价或地区数排序，方便找「最划算的那一个」。

  • 同一套餐出现多行：因为月付、年付、以及源站未标注周期的计费项是分别定价的，行数与「套餐」数不完全一致。
  • 地区数：该套餐在多少个 App Store 地区有独立定价。地区数越少，说明该计费项还只在部分市场提供。
  • 折算汇率：统一用人民币折算，仅用于横向比较；实际扣款以付款时汇率与当地税费为准。

跨区订阅前要权衡的事

价格差往往来自当地的定价档位，而不是「漏洞」。想换区购买之前，至少确认三件事： 一是能否准备对应地区的 Apple ID 与支付方式（多数人用当地 App Store 礼品卡）； 二是续订是否稳定（切回原区、换设备、换卡都可能让订阅失效）； 三是账号风险，部分服务会按账号地区限制功能，也可能违反服务条款。

常见问题

为什么同一个 AI 订阅在不同国家价格不一样？

App Store 的各地区定价由苹果按当地购买力、税费与汇率单独设定，并非简单按汇率换算。苹果每年会调整部分地区的价格档位，加上本币汇率波动，同一订阅在不同地区折算成人民币能差 10%–50%。

跨区订阅（换区买）有什么风险？

常见风险包括：需要对应地区的 Apple ID 与当地支付方式（部分可用礼品卡）、订阅后切换回原区可能导致续订失败、部分服务按 IP 或账号地区限制功能、以及违反平台服务条款的可能。跨区前的账号余额、家庭共享与退款政策也与本地不同。

表里的价格包含税费吗？

App Store 显示价为含当地税费的最终价（部分美国州会另加销售税）。本页统一折算为人民币便于横向比较，折算所用的汇率会随时间变动，因此实际扣款金额以你付款时的汇率为准。
